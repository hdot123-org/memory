## 实现内容

### 1. 备份脚本改造 (`~/.factory/backup/memory-dr-backup.sh`)
- **动态路径枚举**：调用 `evolve_cli backup-paths` 获取全部消费项目的 memory 目录
- **静态路径保留**：9 个核心路径（memory-core、全局知识库、项目地图、.memory-core 等）
- **存在性过滤**：自动跳过不存在的路径，保持健壮性
- **--dry-run 支持**：验证模式，透传给 restic，不实际上传
- **枚举失败处理**：命令失败时仅警告，继续使用静态路径完成备份
- **临时文件管理**：使用 PID 后缀避免冲突

### 2. 测试覆盖 (`tests/test_backup_script_integration.py`)
创建 14 个测试用例，覆盖：
- 脚本结构验证（8 项）
- 动态路径覆盖验证（2 项）
- 行为验证（4 项）

### 3. 实际验证
- **备份目标总数**：22 个（9 静态 + 13 动态）
- **动态路径数**：13 个项目 memory 目录

## 技术亮点

- **双层路径策略**：静态核心 + 动态扩展，兼顾稳定性和扩展性
- **故障隔离**：枚举失败不影响备份执行，符合 §5.5 不变量
- **零密钥落盘**：完全依赖 1Password op:// 引用，符合安全要求
- **并发安全**：保留 mkdir 锁机制，防止重复执行
